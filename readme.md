# Blueprint

A small-scale recreation of the floorplanning engine from [Spoak](https://studio.spoak.com/) —
one of the tools I've been working on since 2020.

**Live demo:** https://meesayen.github.io/project-blueprint/

## About

What started as a simple mockup tool for designers has gradually evolved into a much more
powerful platform, offering advanced mockup capabilities (including a sort of "fake 3D" effect
on 2D mockups) as well as full-fledged floorplanning tools.

This demo showcases just a fraction of what Spoak's floorplanning engine is capable of: drawing
walls with snapping and junctions, automatic room detection, exterior vs. interior wall
rendering.

It's also a project I'm particularly proud of as a developer — something built from the ground
up, evolved over the years, and brought to life largely on my own.
